# 章节写作细则（Chapter Guide）

> 本文件是 prd-gen 的懒加载参考，收录 PRD 各章节的写作细则与格式模板，生成对应章节时读取。

## User Story Format（第 3.2 节用户故事模板）

Each user story follows this template:

```
US-{NN}: [Brief feature description]

As a [user role]
I want [feature description]
So that [business value]

**Acceptance Criteria**:
- Given [precondition]
- When [I do X]
- Then [expected outcome]

**Priority**: P0/P1/P2
**Estimate**: X story points
```
